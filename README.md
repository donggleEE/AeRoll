# AeRoll

AeRoll은 LCC 항공사 AERO_K와의 기업 연계 프로젝트로 제작하는 Flutter 기반 모바일 필름 카메라 앱입니다. 프로젝트 팀이 제작한 색감의 필터로 레트로 필름 감성의 사진을 촬영합니다.

## 주요 기능

- 카메라 화면에서 필터 선택 및 변경
- 미리보기 터치 초점과 초점 위치 표시
- 사진 촬영 타이머 OFF·3·5·10초와 카운트다운 취소
- 지원 카메라의 촬영 플래시 ON·OFF
- 필터별 0~100% 강도 조절과 사용 중 마지막 값 유지
- 전면·후면 카메라 전환
- 예시 사진에 필름을 적용한 썸네일로 필터 선택
- 선택한 필터를 적용한 사진 촬영
- 촬영한 사진을 기기 앨범에 저장
- 앨범에서 저장된 사진 확인
- 두 손가락 핀치 줌과 사진 비율 선택
- 확대 눈금의 세로 드래그로 연속 줌 조절
- 설정 하단 시트의 격자·수평계 켜기와 끄기
- 소리를 포함한 원본 동영상 녹화·정지·저장과 앱 갤러리 재생

## 현재 개발 상태

전체 화면 카메라, 반투명 조작 패널, 원본·warm·cold 필터, 촬영 및 앨범 저장, 앱 갤러리와 사진 상세 화면을 구현했습니다. 이미지 처리와 저장은 별도 처리기와 최대 3장의 저장 큐를 사용합니다. 기존 PNG 필터는 제거하고 고정 감마 인코딩 sRGB 변환으로 교체했습니다.

촬영 후처리 최적화 후 정적 분석, 자동 테스트 101개와 Android 디버그 APK 빌드를 통과했습니다. 이미지 복사와 필터 순회 비용을 줄이고, 저장 실패 시 원본·설정을 보존해 재시도하도록 변경했습니다. 동일 Windows 12MP 입력의 cold 50% 후처리 중앙값은 1,567→1,080ms였으며 수정 전후 JPEG/PNG의 바이트 일치를 확인했습니다. 실제 캡처·기기 앨범 시간과 모바일 FPS를 뜻하는 수치는 아닙니다. 기존 터치 초점·타이머·플래시·줌·필터 기능도 회귀 테스트를 통과했습니다. 자세한 내용은 [촬영 성능 보고서](docs/photo_performance.md)와 [테스트 보고서](docs/test_report.md)를 참고하세요. 다른 ICC 프로필 변환과 실기기·iOS 검증 제한은 유지합니다.

앱 갤러리는 기기 앨범과 별도 사본을 유지합니다. 기기 앨범의 사진을 삭제해도 앱 사본은 남습니다.

## 줌·설정·동영상 확장 상태

2026년 11월 3일 요청에 따라 두 손가락 핀치 줌, 설정 시트의 격자·수평계, 사진 비율 16:9·4:3·1:1, 오디오를 포함한 원본 동영상 녹화·저장과 앱 갤러리 재생을 구현했습니다. 통합 자동 검사·Android 빌드·에뮬레이터 확인을 마쳤습니다. 세로 화면의 사진 영역은 각각 9:16·3:4·1:1이며 남는 공간은 검정으로 표시합니다.

이전 동영상 구현은 원본 영상·소리·기기 앨범 저장이었으며, 이후 사용자가 실제 영상 파일의 필터 적용을 추가 요청했습니다. 사진·영상은 같은 warm·cold 변환 정의를 사용하며 마이크 권한은 영상 모드 진입 때 처리합니다. 기본 설정은 격자 켜짐, 수평계 꺼짐, 사진 16:9입니다.

## 확장 줌과 영상 필터 개발 상태

2026년 11월 4일 실시간 줌·세로 눈금·영상 필터 작업을 재개했습니다. 기본 1배, 최대 100배를 목표로 하며 0.6배는 실제 렌즈 지원 때만 제공합니다. 네이티브 범위를 넘는 배율은 디지털 자르기여서 화질이 낮아질 수 있습니다. 눈금은 줌 상호작용 중 표시하고 마지막 제스처 후 2초 뒤 서서히 숨깁니다.

줌·눈금과 영상 필터를 구현하고 자동 검사 64개와 Android 빌드를 통과했습니다. 실제 Android 네이티브 출력 파일에서 1·2·4·100배와 PNG 합성 픽셀, 소리 트랙과 표시 방향을 비교했고 앱의 필터 영상 녹화·출력·앨범 저장과 재생도 확인했습니다. iOS AVFoundation 코드는 Windows에서 빌드·실행하지 못했습니다. 출력에는 녹화 정지 후 처리 시간이 필요하고 디지털 확대는 화질을 낮출 수 있습니다. 최신 상태는 [개발 계획](docs/project_plan.md)을 확인하세요.

수평계는 흰 고정 기준선과 회전선으로 기울기를 표시하고 ±2도 이내일 때 노란색으로 바뀝니다. 기기를 평평하게 눕혔거나 센서 값을 사용할 수 없으면 수평으로 판정하지 않습니다. 기기 앨범 저장에 실패해 보존한 영상 사본은 앱 갤러리에서 저장 상태를 구분합니다.

새 기능의 구현과 검증 진행 상황은 [개발 계획](docs/project_plan.md)의 최신 절을 참고하세요. 이전 작업의 테스트 25·47개와 최신 64개는 문서에서 구분합니다.

## 실행 방법

Flutter 개발 환경을 준비하고 프로젝트 루트에서 다음 명령을 실행합니다.

```sh
flutter pub get
flutter run
```

## 코드 검증

```sh
flutter analyze
flutter test
```

카메라와 기기 앨범 연동은 Android/iOS 실기기에서도 확인해야 합니다.
