# AeRoll

AeRoll은 LCC 항공사 AERO_K와의 기업 연계 프로젝트로 제작하는 Flutter 기반 모바일 필름 카메라 앱입니다. 프로젝트 팀이 제작한 색감의 필터로 레트로 필름 감성의 사진을 촬영합니다.

## 주요 기능

- 카메라 화면에서 필터 선택 및 변경
- 전면·후면 카메라 전환
- 예시 사진에 필름을 적용한 썸네일로 필터 선택
- 선택한 필터를 적용한 사진 촬영
- 촬영한 사진을 기기 앨범에 저장
- 앨범에서 저장된 사진 확인

## 현재 개발 상태

전체 화면 카메라, 반투명 조작 패널, 라이트·콜드 필터, 촬영 및 앨범 저장, 앱 갤러리와 사진 상세 화면을 구현했습니다. 이미지 합성과 저장은 별도 처리기와 최대 3장의 저장 큐를 사용합니다.

정적 분석, 자동 테스트 25개, Android 디버그 APK 빌드와 에뮬레이터 동작을 확인했습니다. 실제 휴대폰의 촬영 속도·색감과 iOS 동작은 추가 검증이 필요합니다. 자세한 내용은 [테스트 보고서](docs/test_report.md)를 참고하세요.

앱 갤러리는 기기 앨범과 별도 사본을 유지합니다. 기기 앨범의 사진을 삭제해도 앱 사본은 남습니다.

## 실행 방법

Flutter 개발 환경을 준비하고 프로젝트 루트에서 다음 명령을 실행합니다.

```sh
flutter pub get
flutter run
```

## 코드 검증

```sh
flutter analyze
flutter test
```

카메라와 기기 앨범 연동은 Android/iOS 실기기에서도 확인해야 합니다.
